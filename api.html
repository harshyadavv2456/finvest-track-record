Quick start

# what is available + latest dates
curl -s https://harshyadavv2456.github.io/finvest-track-record/api/v1/index.json

# latest model views for India (all stocks)
curl -s https://harshyadavv2456.github.io/finvest-track-record/api/v1/latest/IN.json

# one stock: latest view, moves vs the 3 indices, history, fundamentals
curl -s https://harshyadavv2456.github.io/finvest-track-record/api/v1/ticker/IN/ANANDRATHI.NS.json

Tickers with “&” (e.g. M&M.NS) are written with “-and-” in file names — use the file column of ticker/IN/index.json.

Rules you can rely on

  • Every JSON file has the same envelope: disclaimer, api_version, schema_version, dataset, source, attribution, generated_at_ist, data.
  • Long signals are delayed. Names the model rates INITIATE or ADD for a signal day appear only after that day’s entry price is locked (the entry session’s close + 45 minutes), exactly as on the site. Until then only their count and the unlock time are published (gate). Hold, Avoid and Reduce/Exit are published at once.
  • Disclaimers everywhere. For educational and research purposes only. Not investment advice. Every JSON has a disclaimer field, every CSV starts with a # … comment line (use comment="#" in pandas), and every zip has a README. Files that list long signals also carry long_signal_notice: “These long-signal analyses are model outputs shown for testing and educational purposes only. Not investment advice, not a recommendation to buy or sell.”
  • Price history is Yahoo-sourced. Yahoo Finance-sourced price data, provided for internal/educational use only; Yahoo's redistribution terms may apply. No warranty; adjusted for splits and dividends as served by Yahoo. It lives only in prices/; all other files contain FinVest-sourced values and returns computed by the tracker.
  • Nothing is invented. Missing values are null and flagged; prices are never filled in.
  • Labels are model views, not advice. FinVest’s position-sizing and recommendation-style fields are removed from the copies published here.

Update schedule


FinVest’s own daily run finishes around 14:00 IST. This tracker checks from 14:30 IST, fetches the new signals plus the extra FinVest endpoints (with retries and back-off), stores the raw responses privately, rebuilds and republishes. Expect fresh files on weekdays by about 15:00–16:00 IST; long-signal names appear once the entry price is locked (India: about 16:15 IST on the entry day; US: about 02:15 IST the next morning). Per-ticker FinVest endpoints (about 20 per ticker, ~1,450 tickers) are fetched in paced batches across the day (about 1 request/second, resumable) and prices refresh daily, so ticker detail files fill in over several runs. Each file says when it was generated. History is never pruned: every signal day stays at signals/<date>/<market>.json.



Limitations


    

  • Not real-time and not tick data: one update per day. Weekends/holidays carry the previous data.
    • 

  • Static files only: no query parameters, no filtering. Use the CSVs or per-stock files.
    • 

  • No API keys, no rate-limit promise beyond GitHub Pages’ fair-use limits — please cache and do not poll more than a few times a day.
    • 

  • Data comes from FinVest’s public API, Yahoo Finance price history and calculations based on it; it can be late, wrong or missing and is not guaranteed. FinVest endpoints that were empty or unavailable are listed below.
    • 

  • Prices are in local currency (INR / USD). Index comparisons use price indices.
